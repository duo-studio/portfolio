Duo Studio concept notes

A type-led marquee for a complex performing arts center.

The new direction moves away from a card-heavy dashboard and toward an editorial first view: the headline leads, the event art supports, and the schedule gives visitors something immediate to act on.

Concept angle

Start with what's on at Atlas.

The concept treats Atlas like a live venue with many doors in: the schedule is visible immediately, but the page still explains the building's range.

1

The hero is type-led, not image-led.

The largest statement tells visitors what the page is for: start with programming. The image supports the message instead of carrying the whole hero.

2

The event art keeps its full ratio.

Young John Lewis is used as a wide marquee banner, preserving the original artwork and avoiding the awkward crop problem from earlier passes.

3

The first view keeps the schedule visible and visual.

The right-side "What's on next" module uses larger image-led rows, with dates folded into the content area so each event reads as one clear choice.

4

Real imagery adds depth without overpromising.

The concept uses Atlas-owned event thumbnails and a venue image instead of a new icon or illustration system. That gives the page texture while staying believable for the existing site.

5

Mobile keeps the order practical.

The mobile concept stacks logo, headline, CTAs, ratio-safe event marquee, visit facts, image-led schedule rows, and audience paths so the complexity unfolds in sequence.

The design stays Atlas-specific.

The concept uses Atlas's typography direction, deep teal-blue, Atlas blue, cyan link accents, the site's red-orange urgency color, real event and venue imagery, and language that fits a working performing arts center.
